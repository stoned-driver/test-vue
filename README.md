# Project & Task Manager

SPA для управління проектами і завданнями — Vue 3 (Composition API) + TypeScript + Pinia.

> 🚧 В розробці. Повний опис архітектури, посилання на розгорнуту версію та інструкція запуску з'являться тут.

## Локальний запуск

```sh
npm install
npm run dev
```

## Скрипти

| Команда             | Призначення                          |
| ------------------- | ------------------------------------ |
| `npm run dev`       | Дев-сервер із HMR                    |
| `npm run build`     | Type-check + продакшн-збірка         |
| `npm run test:unit` | Юніт-тести (Vitest)                  |
| `npm run lint`      | Лінтинг (oxlint + ESLint)            |
| `npm run format`    | Форматування коду (Prettier)         |
